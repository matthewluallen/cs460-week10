What you're looking at

Boot
Every beat of the power-on is a real self-test.

The visual language

fill = value (energized)
empty = de-energized
violet border =  forced  (a human is lying to the logic)
cyan ring = focus
amber = REMOTE / caution
red = fault / NET-WROTE
Fill tells you what's true. Border tells you if someone is lying about it. The mode word is always the biggest thing on the glass.

# Selected bus-study packet notices

The project owner authorized educational sharing with students. This covers this
selected packet, not a blanket open-source license for the entire repository.
Decoder JavaScript and selected firmware excerpts are project-authored material;
the original files and comments are retained. Captures come from the project's
owned physical bench. They contain historical diagnostic evidence, not student
data, access codes, a full firmware image or a current hardware connection.

Node.js, Logic Studio, Wireshark, reference publications, instrument software and
device firmware are not bundled. Install or distribute external runtimes under
their own licenses. The full Studio and original diagnostic source have separate
content-review boundaries; this package does not silently sanitize those sources
or qualify them for a blind discovery assessment. The selected identity projection
states exactly which source fields it preserves. This is source-assisted study.
